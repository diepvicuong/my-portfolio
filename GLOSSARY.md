# Portfolio Positioning

Canonical language for describing the professional identity and proof presented by this portfolio.

## Language

**Senior Mobile Engineer**:
A mobile specialist with 5+ years of experience whose core expertise is Flutter and native Android, and who can own delivery from product requirements through production release.
_Avoid_: Full-stack Developer, Flutter coder

**Supporting backend capability**:
The ability to integrate APIs and contribute to backend or web work when delivery requires it, without claiming backend or web as a primary specialization.
_Avoid_: Full-stack expertise, backend specialist

**Flagship case study**:
One of three selected projects used to demonstrate ownership, technical judgment, architecture, production problem-solving, and measurable outcomes in depth.
_Avoid_: Project card, portfolio item

**Mobile Systems Lab**:
The portfolio's visual concept: a calm, precise engineering workspace built around mobile devices, architecture layers, data flow, and release signals.
_Avoid_: Hacker theme, generic developer illustration
