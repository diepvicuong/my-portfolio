## Question

Which concrete composition, typography, color system, device/system imagery, and motion language makes Mobile Systems Lab feel distinctive, credible, and Senior-level across desktop and mobile? Build three radically different, throwaway UI variants on a shareable preview route, then let the user choose one or combine parts before the information architecture is finalized.

## Preview requirement

This ticket must produce a user-reviewable prototype with three structurally different variants and a `?variant=` switcher. The prototype is not production code and must be removed or captured on a throwaway branch after the user selects the direction.
