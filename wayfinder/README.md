# Local Wayfinder Tracker

This repository has no configured remote issue tracker, so this directory is the canonical local Markdown tracker for the portfolio planning effort.

- Each file in `issues/` is an issue.
- `Parent` identifies child issues of a map.
- `Blocked by` records dependencies using issue names and relative links.
- An open issue with no unresolved blockers and no assignee is on the frontier.
- Claim an issue by filling in `Assignee` before working it.
- Resolve an issue by adding a `## Resolution` section and changing `Status` to `closed`.
- Append a one-line link to the map's `Decisions so far` when a child issue closes.
