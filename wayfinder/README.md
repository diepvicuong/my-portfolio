# Wayfinder planning mirror

The canonical issue tracker for this repository is GitHub Issues. This directory is the versioned planning mirror and seed source for the map and tickets; issue state, child relationships, and blocking dependencies live on GitHub.

- Each file in `issues/` mirrors a GitHub issue.
- `Parent` identifies child issues of a map.
- `Blocked by` records dependencies using issue names and relative links.
- GitHub's native dependencies determine the live frontier.
- Claim an issue by filling in `Assignee` before working it.
- Resolve an issue in GitHub by posting the answer as a comment and closing it.
- Append a one-line GitHub issue link to the map's `Decisions so far` when a child issue closes.
